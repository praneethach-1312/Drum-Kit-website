# Drum Kit Website 🥁

An interactive drum kit website where users can play different drum sounds using keyboard keys or mouse clicks.

## 🚀 Features
- Play drum sounds using keyboard keys
- Button click animations
- Interactive user interface
- Responsive design

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
